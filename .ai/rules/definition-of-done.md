# Definition of Done

## Functional

- all approved acceptance criteria implemented
- normal and relevant alternative/error flows work
- business rules preserved
- no unrelated behaviour changed

## Technical

- correct layers changed
- contracts consistent
- migration included if needed
- security handled
- errors handled
- idempotency/concurrency preserved where relevant

## Quality

- build succeeds
- relevant tests pass
- no unintended diff

## Documentation

- current state updated when status changed
- use case updated when implementation changed
- architecture/rules/flows/glossary/overview updated only when affected

## Exit

Do not implement future features, nice-to-haves, unrelated optimisation, or opportunistic refactoring.

When complete, stop.
