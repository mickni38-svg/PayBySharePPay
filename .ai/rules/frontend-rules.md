# Frontend Rules

- Use Angular standalone components.
- Use Signals where existing code does.
- Reuse current services and interceptor.
- Preserve lazy-loaded routes.
- Keep mobile-first design.
- Keep styles local unless genuinely shared.
- Do not introduce NgRx.
- Do not add dependencies without approval.
- Keep API URLs in environment configuration.
- Preserve localStorage auth keys unless auth is the task.
- Use PayNSync in UI.
- Maintain accessibility and touch targets.
