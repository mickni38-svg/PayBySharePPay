# DevOps Rules

- Hosting remains Simply.com unless approved otherwise.
- API publish remains self-contained `win-x64`.
- Deployment uses FTP and `app_offline.htm`.
- Production deploy remains manual unless explicitly approved.
- Never echo secrets.
- Use GitHub Secrets references.
- Keep build and deploy separate.
- PR builds must not deploy.
- Validate API, frontend, landing page, and merchant demo paths separately.
- Preserve environment-specific Angular configuration.
